# GalacticNews — Галактический Вестник

веб-приложение для просмотра новостей на asp.netCore mvc
позволяет просматривать список новостей и открывать каждую на отдельной странице с детальным содержанием.

---

## технологии

- **.net 9** — платформа для разработки
- **asp.net core mvc** — паттерн Model View Controller для веб-приложения
- **entity framework core 9** — orm для работы с базой данных
- **SQLite** - в качестве встраиваемой базы данных
- **razor, html, css, linq** - япы

### работа приложения

1. **Маршрутизация**  
   По умолчанию запросы направляются в `NewsController.Index()`

2. **Получение данных**  
   Контроллер через `AppDbContext` обращается к таблице `news`
   Запросы формируются с помощью LINQ

3. **Пагинация**  
   На главной странице отображается 4 новости. При клике на номер страницы или стрелки `?page=N` передается в контроллер, и выбирается соответствующий блок записей

4. **Страница подробностей**  
   При клике «ПОДРОБНЕЕ» переход на `/News/Details/{id}?page={current}`  
   Контроллер находит новость по `Id` и передаёт её в представление `Details.cshtml`
   Кнопка «НАЗАД К НОВОСТЯМ» возвращает на тот же номер страницы

5. **Отображение**  
   Все представления используют общий макет `_Layout.cshtml` с шапкой, футером и подключёнными стилями

## запуск проекта

1. **склонируйте проект**

```bash
git clone https://github.com/qvortex-beem/GalacticNews
cd GalacticNews
dotnet run
```

2. **откройте браузер**

лучше всего подойдет стандартно настроенный google chrome
перейдите по адресу `https://localhost:5000` или `http://localhost:5000`
